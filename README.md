# YuvaIntern_week4_Supervised_Learning
Titanic Survival Prediction Using Supervised Learning

Project Overview

This project predicts passenger survival on the Titanic dataset using supervised machine learning.

Objective

To build and evaluate a Logistic Regression classification model using passenger information.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Google Colab

Methodology

1. Dataset loading and inspection
2. Missing-value handling and preprocessing
3. Feature encoding and scaling
4. Train-test split
5. Logistic Regression model training
6. Evaluation using accuracy, precision, recall, and F1-score
7. Five-fold cross-validation and baseline comparison

Results

Actual evaluation metrics are available in the project notebook.

Limitations

The model uses selected passenger features and may not generalize to every population or dataset.

Conclusion

This project demonstrates a supervised learning workflow for a binary classification problem.
